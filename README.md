One sentence, at most 200 characters, about the best meal ever had — written by a small Python program (pure standard library) for make.fun's "The Best Meal You Ever Had" bounty. A judge model reads the sentences two at a time and keeps the one that makes the meal feel most real.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (creating the directory if needed). The output is fixed, so every run produces byte-identical text.
